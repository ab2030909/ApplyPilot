## 1. Understand the product first

Project location:
`C:\Users\Abdullah\Desktop\applyforme`

Study the actual project, README, dashboard, Chrome extension, and available assets before producing the video.

ApplyPilot AI is a Chrome extension with a web dashboard that helps job seekers manage and simplify job applications.

Its capabilities include:

- **Smart Autofill:** Detects job application form fields and fills them using the user's saved profile.
- **Resume Management:** Upload, manage, and select multiple PDF/DOCX resumes.
- **Job Analyzer:** Extracts important information from job descriptions.
- **AI Job Matching:** Compares a candidate's resume with job requirements and identifies matching and missing skills.
- **AI Cover Letter Generator:** Creates personalized cover letters.
- **Application Assistant:** Helps answer application questions using the candidate's actual qualifications.
- **Resume Optimizer:** Suggests improvements for a particular job.
- **Job Tracker:** Tracks applications through Saved, Applied, Assessment, Interview, Offer, Rejected, and Withdrawn.
- **Privacy-first approach:** User data is stored locally by default. AI processing is optional and requires backend configuration.

Important product rules:
- ApplyPilot AI never automatically submits job applications.
- Autofill offers a preview and lets users select fields.
- Do not portray AI features as verified unless they have actually been tested.
- Never invent features or show fake integrations.
- Do not show fabricated testimonials, user numbers, ratings, or statistics.
